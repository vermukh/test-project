# СтройМатериалы (Laravel)

Проект разворачивается одной командой: скрипт сам:
- проверяет PHP и нужные расширения;
- при необходимости устанавливает Composer;
- ставит зависимости `composer`;
- создаёт `.env` (или использует готовый);
- запрашивает только параметры подключения к БД;
- генерирует `APP_KEY`;
- выполняет миграции и сиды.

## Быстрый старт

```bash
chmod +x setup.sh
./setup.sh
```

### Запуск на Windows (`.bat`)

Откройте `PowerShell` или `cmd`, перейдите в папку проекта и выполните:

```bat
setup.bat
```

Альтернативно можно запустить файл двойным кликом по `setup.bat` в Проводнике.

После запуска скрипт попросит ввести:
- `DB_HOST`
- `DB_PORT`
- `DB_DATABASE`
- `DB_USERNAME`
- `DB_PASSWORD`

## Что добавлено в БД

- Отдельные миграции под предметную область (`roles`, `users`, `categories`, `manufacturers`, `suppliers`, `units`, `products`, `pickup_points`, `order_statuses`, `orders`, `order_items`).
- Сиды с данными из исходного SQL-скрипта.
